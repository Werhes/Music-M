# Time Tracker

**Версия:** 1.0.0
**Автор:** VK M Community
**Тип:** Утилита

## Описание

**Time Tracker** — это аддон для VK M, который отслеживает время, проведённое в приложении. Ведите учёт своего времени и получайте забавные уведомления о достижениях!

## Возможности

- ⏱ **Общее время** — сколько всего времени вы провели в VK M
- 📅 **Время за сегодня** — сколько времени вы слушаете музыку сегодня
- 🏆 **Достижения** — уведомления при достижении 1, 5, 10, 24, 50, 100, 200, 500 и 1000 часов
- 💾 **Автосохранение** — данные сохраняются каждые 30 секунд и при закрытии приложения
- 📊 **Статистика** — можно запросить через другие аддоны

## Использование

1. Установите аддон через **Магазин дополнений**
2. Аддон активируется автоматически
3. При первом запуске появится уведомление
4. При достижении очередного порога времени появится уведомление с поздравлением

## Где хранятся данные

Все данные сохраняются в базу данных VK M (таблица `SettingsTable`) с префиксом `timetracker_`:
- `timetracker_total_seconds` — общее время в секундах
- `timetracker_today_seconds` — время за сегодня
- `timetracker_today_date` — дата последнего сброса
- `timetracker_last_achievement` — последнее полученное достижение (в часах)
- `timetracker_first_launch` — дата первого запуска

## Совместимость

Требуется VK M версии 1.0.0 или выше.
